# Contributing to SeedSpark

Thank you for helping grow this movement.

## Ways to contribute

1. **Start a real Seed** and share the results (open an issue with photos / numbers).
2. **Improve the protocol** – make the JSON schema clearer or more useful.
3. **Add templates** – high-leverage climate actions that work in different cultures and climates.
4. **Translate** – README, templates, and UI strings.
5. **Build UI** – better web or mobile experience (PWA preferred).
6. **Write documentation** – how real communities used SeedSpark.
7. **Report bugs** or suggest features via Issues.

## Development

```bash
git clone https://github.com/rorito-alt/SeedSpark.git
cd SeedSpark
python -m seedspark.cli --help
python -m seedspark.server
```

No heavy dependencies required for the core.

## Code of Conduct

Be kind, constructive, and focused on climate impact. We prioritize actions that reduce emissions, increase resilience, and build community power over performative activity.
